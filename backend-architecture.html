🔄 3-Tier Multi-User Sync Pipeline & Data Lifecycle

How data flows seamlessly between client devices and the central Google Sheets master database.

1

Tier 1: Client Local Vault (<5ms)

Guarantees 100% offline functionality and instant optimistic UI updates.

  • IndexedDB (EphphathaLocalVault_v3)
  • AES-256-GCM Web Crypto: Personal prayer reflections are encrypted before storage.
  • Memory Mirror prevents split-brain.
  • Sync Outbox queues changes if offline.
2

Tier 2: Edge Worker / Proxy Routing

Bypasses browser CORS constraints and handles high-frequency rate-limiting.

  • Cloudflare Edge Worker (/api/sheet-proxy)
  • Local Express Proxy during local development.
  • HTTP 206 Streaming Proxy for audio playback.
  • Direct GAS text/plain fallback if edge is offline.
3

Tier 3: Google Sheets Master DB

Serverless multi-user relational storage engine inside Google Workspace.

  • Google Apps Script Web App (doPost / doGet)
  • LockService (10s) prevents multi-user race conditions.
  • Auto-Provisioning creates all 6 sheets if absent.
  • Zero infrastructure costs or server management.
