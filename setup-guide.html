Step 1: Automated Google Drive Folder & Master DB Provisioning

1-Click Google Apps Script

Instead of manually creating 14 folders and configuring spreadsheet columns, run this Google Apps Script once to automatically generate Ephphatha_Cloud_Root/, 00_System_Manifest_And_DB/, all 12 Salvation History Period folders (01_Early_World through 12_The_Church), and the relational Ephphatha_Master_DB Google Sheet.

  1. Open https://script.google.com and click New Project.
  2. Click Copy Script below and paste it into the editor, replacing any existing code.
  3. Click Run (▶) on provisionEphphathaGoogleDriveHierarchy and grant Drive/Sheets permission when prompted.
  4. Copy the output JSON from the Execution Log (contains your Folder IDs and Master Sheet ID).
function provisionEphphathaGoogleDriveHierarchy() {
  var rootFolder = getOrCreateFolder_(DriveApp.getRootFolder(), 'Ephphatha_Cloud_Root');
  var periodFolders = [
    '00_System_Manifest_And_DB',
    '01_Early_World', '02_Patriarchs', '03_Egypt_And_Exodus',
    '04_Desert_Wanderings', '05_Conquest_And_Judges', '06_Royal_Kingdom',
    '07_Divided_Kingdom', '08_Exile', '09_Return',
    '10_Maccabean_Revolt', '11_Messianic_Fulfillment', '12_The_Church'
  ];

  var folderManifest = {};
  periodFolders.forEach(function(name) {
    var sub = getOrCreateFolder_(rootFolder, name);
    folderManifest[name] = { id: sub.getId(), url: sub.getUrl() };
  });

  var systemFolder = DriveApp.getFolderById(folderManifest['00_System_Manifest_And_DB'].id);
  var ss = SpreadsheetApp.create('Ephphatha_Master_DB');
  DriveApp.getFileById(ss.getId()).moveTo(systemFolder);

  var users = ss.getActiveSheet();
  users.setName('Users');
  users.appendRow(['user_id', 'display_name', 'auth_method', 'streak_days', 'grace_shields', 'updated_at']);

  var cohorts = ss.insertSheet('Fellowship_Cohorts');
  cohorts.appendRow(['cohort_id', 'cohort_name', 'invite_code', 'member_name', 'member_contact', 'status', 'amens_count', 'updated_at']);

  var logs = ss.insertSheet('Progress_Logs');
  logs.appendRow(['log_id', 'user_id', 'day_number', 'completed', 'audio_timestamp_sec', 'hmac_signature', 'synced_at']);

  Logger.log(JSON.stringify({ rootId: rootFolder.getId(), masterSheetId: ss.getId(), folders: folderManifest }, null, 2));
}

function getOrCreateFolder_(parent, name) {
  var iter = parent.getFoldersByName(name);
  return iter.hasNext() ? iter.next() : parent.createFolder(name);
}

Step 3: Deploy Edge Audio & Security Proxy Worker (Zero Secret Exposure)

HTTP 206 + Rate Limiting

Deploy scripts/cloudflare-edge-worker.js to Cloudflare Workers (Free Tier: 100,000 requests/day) to enforce Accept-Ranges: bytes (HTTP 206 instant audio scrubbing), Token-Bucket Rate Limiting (30 req/min), and keep your Google Cloud credentials 100% hidden from browser DevTools.

Part 3A: Get Your Google Drive API Key (Takes 60 Seconds — Never Expires)

  1. In Google Drive, right-click your Ephphatha_Cloud_Root folder → Share → Set General Access to "Anyone with the link can Viewer" (so the Edge Worker can stream audio files using your restricted API key).
  2. Open Google Cloud Console — Google Drive API and click Enable.
  3. Go to APIs & Services → Credentials → + Create Credentials → API Key.
  4. Click Edit API Key → Under API restrictions, select Restrict key → Check Google Drive API → Save and copy your API key (starts with AIza...).

Part 3B: Deploy Worker via Cloudflare Browser Dashboard (No CLI Needed)

  1. Sign in to the free Cloudflare Dashboard → Click Workers & Pages (left sidebar) → Create → Create Worker.
  2. Name it ephphatha-edge-proxy and click Deploy.
  3. Click Edit Code, replace the default code in worker.js with the contents of scripts/cloudflare-edge-worker.js, and click Deploy (top right).
  4. Go back to your Worker overview → Click Settings → Variables and Secrets → + Add:
    • Type: Secret
    • Variable name: GDRIVE_API_KEY
    • Value: Paste your AIza... Google Drive API Key → Click Deploy.
  5. Test your worker by visiting https://ephphatha-edge-proxy.<your-subdomain>.workers.dev/health — it will return {"status":"Ephphatha Edge Gateway Active","authConfigured":true}!
