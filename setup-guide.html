Step 1: Deploy Google Sheets Master DB Web App (Multi-User Cloud Sync & Login Restore)

Google Apps Script Web App

This Google Apps Script turns your Google Sheet (Ephphatha_Master_DB) into a serverless real-time database. It automatically creates 6 relational tabs (Users, Progress_Logs, Fellowship_Cohorts, Cohort_Members, Cohort_Reflections, Cohort_Prayers), saves user progress, restores reading progress when users log in on any device, and synchronizes Fellowship Cohort reflections & prayer requests across multiple users.

  1. Open your Google Sheet (or go to https://script.google.com and click New Project).
  2. Click Copy Script below and paste it into the Apps Script editor, replacing any existing code.
  3. Click Deploy (top right) → New deployment:
    • Select type (⚙️ icon): Web app
    • Description: Ephphatha Master DB Sync Engine
    • Execute as: Me (your Google account)
    • Who has access: Anyone (allows the web app & Edge proxy to sync)
  4. Click Deploy, authorize permissions, and Copy the Web App URL (looks like https://script.google.com/macros/s/.../exec).
  5. Open Ephphatha → Tap ⚙️ Settings → Section 2 (Google Sheets Backend) → Paste your Web App URL and tap 🔗 Connect Sheet!
/**
 * EPHPHATHA MASTER DATABASE & REAL-TIME MULTI-USER CLOUD SYNC ENGINE
 * Paste this into Google Apps Script and Deploy as a Web App (Access: Anyone).
 */
const SHEET_NAMES = { USERS: 'Users', PROGRESS: 'Progress_Logs', COHORTS: 'Fellowship_Cohorts', MEMBERS: 'Cohort_Members', REFLECTIONS: 'Cohort_Reflections', PRAYERS: 'Cohort_Prayers' };
const SHEET_HEADERS = {
  Users: ['user_id', 'display_name', 'email_or_contact', 'auth_method', 'streak_days', 'grace_shields', 'active_cohort_code', 'last_active_day', 'updated_at'],
  Progress_Logs: ['user_id', 'day_number', 'completed', 'audio_timestamp_sec', 'updated_at'],
  Fellowship_Cohorts: ['cohort_id', 'invite_code', 'cohort_name', 'created_by_user_id', 'created_at', 'updated_at'],
  Cohort_Members: ['invite_code', 'member_id', 'name', 'role', 'current_day', 'completed_count', 'streak_days', 'activity_status', 'encouragements', 'updated_at'],
  Cohort_Reflections: ['invite_code', 'reflection_id', 'author_id', 'author_name', 'day_number', 'passage_ref', 'content', 'amen_count', 'created_at'],
  Cohort_Prayers: ['invite_code', 'prayer_id', 'author_id', 'author_name', 'is_anonymous', 'category', 'content', 'praying_count', 'is_answered', 'created_at']
};

function doGet(e) { return handleRequest_(e ? e.parameter : {}, null); }
function doPost(e) {
  var p = e ? e.parameter : {}, body = p;
  if (e && e.postData && e.postData.contents) {
    try { body = JSON.parse(e.postData.contents); } catch(_) { body = p; }
  }
  return handleRequest_(p, body);
}

function handleRequest_(p, b) {
  var action = (p.action || (b && b.action) || 'ping').toLowerCase();
  var payload = b && b.payload ? b.payload : (b || p);
  try {
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    for (var k in SHEET_HEADERS) {
      if (!ss.getSheetByName(k)) { var s = ss.insertSheet(k); s.appendRow(SHEET_HEADERS[k]); s.setFrozenRows(1); }
    }
    var res = { ok: true, action: action, timestamp: new Date().toISOString() };
    if (action === 'ping') { res.spreadsheetTitle = ss.getName(); res.spreadsheetId = ss.getId(); }
    else if (action === 'login' || action === 'getuser') { res.data = handleGetUser_(ss, payload); }
    else if (action === 'syncuser' || action === 'saveuser') { res.data = handleSaveUser_(ss, payload); }
    else if (action === 'getcohort') { res.data = handleGetCohort_(ss, payload); }
    else if (action === 'savecohort') { res.data = handleSaveCohort_(ss, payload); }
    else if (action === 'syncprogress') { res.data = handleSyncProgress_(ss, payload); }
    return ContentService.createTextOutput(JSON.stringify(res)).setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ ok: false, error: err.message })).setMimeType(ContentService.MimeType.JSON);
  }
}

Step 3: Deploy Edge Audio & Security Proxy Worker (Zero Secret Exposure)

HTTP 206 + Rate Limiting

Deploy scripts/cloudflare-edge-worker.js to Cloudflare Workers (Free Tier: 100,000 requests/day) to enforce Accept-Ranges: bytes (HTTP 206 instant audio scrubbing), Token-Bucket Rate Limiting (30 req/min), and keep your Google Cloud credentials 100% hidden from browser DevTools.

Part 3A: Get Your Google Drive API Key (Takes 60 Seconds — Never Expires)

  1. In Google Drive, right-click your Ephphatha_Cloud_Root folder → Share → Set General Access to "Anyone with the link can Viewer" (so the Edge Worker can stream audio files using your restricted API key).
  2. Open Google Cloud Console — Google Drive API and click Enable.
  3. Go to APIs & Services → Credentials → + Create Credentials → API Key.
  4. Click Edit API Key → Under API restrictions, select Restrict key → Check Google Drive API → Save and copy your API key (starts with AIza...).

Part 3B: Deploy Worker via Cloudflare Browser Dashboard (No CLI Needed)

  1. Sign in to the free Cloudflare Dashboard → Click Workers & Pages (left sidebar) → Create → Create Worker.
  2. Name it ephphatha-edge-proxy and click Deploy.
  3. Click Edit Code, replace the default code in worker.js with the contents of scripts/cloudflare-edge-worker.js, and click Deploy (top right).
  4. Go back to your Worker overview → Click Settings → Variables and Secrets → + Add:
    • Type: Secret
    • Variable name: GDRIVE_API_KEY
    • Value: Paste your AIza... Google Drive API Key → Click Deploy.
  5. Test your worker by visiting https://ephphatha-edge-proxy.<your-subdomain>.workers.dev/health — it will return {"status":"Ephphatha Edge Gateway Active","authConfigured":true}!
